# MySkills

Practical agent skills that support engineering judgment with focused guidance and context-sensitive tradeoffs.

## Install

Install with the [skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add Potirniche-Carmine/MySkills
```

## Skills

- [rust-engineering](skills/rust-engineering/SKILL.md) — Rust guidance on ownership, API design, correctness, performance, and verification. Built for capable agents and experienced engineers, without blanket bans or rigid workflows.
